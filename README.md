# 跨境运营手册

面向跨境电商卖家的中文实操清单。按选品、定价、上架、履约和内容测试查找步骤，复制记录模板到自己的表格使用。

[在线阅读](https://treeseago.github.io/cross-border-playbook/) · [网页源码](index.html)

| 指南 | 能拿走什么 |
| --- | --- |
| 单商品选品记录卡 | 需求、供应和试单记录模板 |
| 一单到底能赚多少 | 单单贡献利润拆解和虚构算例 |
| 单商品发布前检查表 | 货品资料、发布及回查清单 |
| 首单打包与发货核对 | 实重、计费重和轨迹核对模板 |
| 短视频开场怎么做小测试 | 单变量内容测试记录模板 |

将仓库下载后直接打开 `index.html` 即可浏览。站点使用单个 HTML 文件，GitHub Pages 可以直接从默认分支的根目录发布。

本手册只收录通用方法及虚构样例。平台费用、类目、承运商及履约规则以操作时的官方后台信息为准。提交改进示例时请使用虚构商品和脱敏数据。

欢迎公开阅读，也可复制这些记录模板并按自己的经营场景调整。
